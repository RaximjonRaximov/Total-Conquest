# Infinite Tower

Hero-squad tower campaign mobile game (HTML5). Built step by step.

## Stack
- HTML5 + vanilla JS
- [Vite](https://vitejs.dev/) dev server / bundler

## Develop
```bash
npm install
npm run dev      # start dev server (http://localhost:5173)
npm run build    # production build -> dist/
npm run preview  # preview the production build
```

## Status
- **Phase 0:** Loading screen — fullscreen pixel-art bg, banner, running knight progress bar.
- **Phase 1 (current):** Kingdom movement — top-down 2D kingdom map, 4-direction knight walk animation, WASD + mobile joystick, collision detection, camera follow.

Next steps: Combat system, inventory UI, and the Infinite Tower entry.
